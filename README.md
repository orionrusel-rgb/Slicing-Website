# Hidden Wonders — Discover Indonesia

Website pariwisata Indonesia: Raja Ampat, Gunung Bromo, Wae Rebo, Nusa Penida, dan destinasi tersembunyi lainnya.

Dibangun dengan HTML, CSS, dan JavaScript (+ Tailwind CSS via CDN).

## Lihat situsnya

Aktifkan GitHub Pages di repo ini (Settings → Pages → Deploy from a branch → `main`), lalu buka:

https://orionrusel-rgb.github.io/Slicing-Website/

## File

- `index.html` — halaman utama
- `slicing1.css` — stylesheet
- `slicing1.js` — interaksi (pencarian, modal, toast, dll.)
- `foto 1.png` – `foto 5.png` — foto destinasi
